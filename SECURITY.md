# Security Policy

## Supported versions

Only the latest release of this registry receives security fixes.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/rafaelherik/agent-marketplace/security/advisories/new).
Include a description, the affected skill or script, reproduction steps, and the
impact you expect.

You can expect an acknowledgement within 7 days. Once the issue is confirmed, a fix
is released and a security advisory is published with credit to the reporter, unless
you ask to stay anonymous.
